# Repository instructions

## Repository language

- Use English for all repository-authored text: interface labels, messages, errors, default names, code comments, documentation, test descriptions, configuration descriptions, commit messages, and GitHub issue and pull request titles, descriptions, checklists, status updates and comments.
- Apply this rule even when the conversation with the user is in Italian or another language.
- Conversation with the user may remain in Italian. Preserve user-supplied names, imported survey data, proper names, and format-defined identifiers or compatibility aliases in their original form.
- Preserve issue states, completion checkboxes, references and dependencies when translating or synchronizing issues.
- Keep code identifiers, file paths, coordinate-system codes and source data unchanged.
